> 版本 v0.1 · 草案阶段 · 本文档是所有内容生成的唯一权威依据

## 1. 概述

| 项 | 说明 |
|---|---|
| 类型 | 修仙题材开放世界 RPG（2D 俯视角 + 文字叙事） |
| 平台 | 移动浏览器优先（PWA 可加主屏），桌面浏览器兼容 |
| 发布 | GitHub Pages / Cloudflare Pages，纯静态，零后端 |
| 基调 | 凡人流：资质平庸的主角，靠谨慎、机缘与坚韧步步登天 |
| 美术 | 国风水墨 UI + 像素角色场景混合风格 |

### 1.1 设计支柱（一切取舍的判断标准）

1. **凡人感** —— 主角不是天才。资源稀缺、境界瓶颈真实存在，突破需要积累与机缘。
2. **探索驱动** —— 大地图上的每一处秘境、每一个 NPC 都可能藏着机缘或杀机。
3. **配置化内容** —— 所有物品/功法/剧情均为 JSON 数据，可无限扩展。
4. **碎片可玩** —— 单次 3-5 分钟有事可做（挂机修炼、一次历练、一段剧情）。

### 1.2 核心循环

```
探索大地图 → 触发事件/任务 → 获得资源(灵石/药材/功法)
     ↑                              ↓
境界突破 ← 修炼(消耗灵气/丹药) ← 战斗/炼丹/交易
```

长线目标：从炼气一层到飞升，每个大境界是一章主线。

## 2. 境界体系

| 境界 | 层数 | 寿元 | 解锁内容 |
|---|---|---|---|
| 凡人 | - | ~80 | 序章：七玄门杂役 |
| 炼气 | 1-13 | ~120 | 灵气感知、基础法术、御器飞行(低空) |
| 筑基 | 初/中/后/圆满 | ~200 | 神识外放、法器→法宝、进入坊市内城 |
| 结丹 | 同上 | ~400 | 元婴老祖座下听道、灵兽契约 |
| 元婴 | 同上 | ~800 | 分神操控第二法身、跨海远行 |
| 化神 | 同上 | ~1500 | 领悟法则雏形、界面传送阵 |
| 炼虚→合体→大乘 | - | ~3000+ | 终章：渡劫飞升（资料片预留） |

### 2.1 突破规则

- **小层突破**（炼气 1→2）：灵气值攒满即可，纯数值。
- **大境界突破**（炼气→筑基）：
  - 硬性条件：灵气圆满 + 对应突破丹药（筑基丹）
  - 概率机制：基础成功率受 根骨/悟性/丹药品质 影响，失败损失灵气并受伤（**不删档不降境界**——手机玩家容错要高）
  - 机缘加成：特定地点突破有额外成功率（如灵脉洞穴 +15%）

## 3. 属性系统

| 属性 | 来源 | 作用 |
|---|---|---|
| 灵力(HP) | 体质/功法 | 归零即重伤回档 |
| 灵气(MP) | 境界/功法 | 施展法术、驱动法器的燃料 |
| 攻击 | 法器+功法+境界 | 战斗伤害 |
| 防御 | 护甲+炼体功法 | 减伤 |
| 神识 | 境界+特殊功法 | 探查、御使多件法器、抗幻术 |
| 根骨 | 天生+洗髓丹 | 修炼速度、突破率 |
| 悟性 | 天生+机缘事件 | 学习功法速度、领悟概率 |
| 声望 | 任务/事件 | 坊市物价、NPC 态度、门派收录 |

## 4. 核心系统

### 4.1 功法（content/skills/）

- 分类：心法（被动+灵气回复）、剑诀/法术（主动）、身法（闪避位移）、炼体（防御）、神通（大招）
- 品阶：凡品 < 黄品 < 玄品 < 地品 < 天品（对应 schema 中 Grade 枚举，后续对齐调整）
- 每部功法按境界分层（如长春功炼气期 13 层），逐层解锁效果
- 获取途径：任务奖励 / 秘境拾取 / 门派兑换 / 击败掉落 / NPC 传功

### 4.2 装备与炼器

- 槽位：武器 / 护甲 / 饰物 ×2
- 词条：固定属性 + 0~3 条随机词条（品阶越高词条越多）→ 掉落多样性
- 炼器玩法（二期）：材料 + 图纸 + 炼器炉，产出可鉴定

### 4.3 丹药与炼丹（一期核心付费点替代——肝度调节阀）

- 丹药类型：回复类 / 突破辅助类 / 永久增益类（洗髓丹+根骨）/ 功能类（隐匿符）
- 炼丹：药材 ×N + 丹方 + 火候小游戏（点击节奏）→ 成功率受悟性影响
- 失败产废丹，废丹可出售——保证负反馈不致命

### 4.4 战斗

- **回合制指令战斗**（手机友好），速度决定出手序
- 指令：攻击 / 法术（选功法）/ 丹药 / 逃跑
- 敌人有意图提示（"此妖兽蓄势欲扑"）→ 决策有信息依据
- 特殊战：偷袭先手、遁地逃跑成功率受身法影响——保留"打不过就跑"的凡人味

### 4.5 灵兽（二期）

- 契约 / 喂养 / 进化，跟随探索提供被动增益

## 5. 世界观与地图

### 5.1 世界结构（致敬凡人流的原创世界观）

```
人界·越国区域（一期）
├─ 七玄门（起点：凡人门派，杂役生涯）        [新手村]
├─ 彩霞山脉（低级妖兽、药草采集）            [练级区]
├─ 黄枫谷（正道七大派之一，主角拜入）        [主城]
│   ├─ 百药园 / 藏经阁 / 器阁 / 任务殿
├─ 太岳山脉（筑基级妖兽、灵矿）              [中期]
├─ 落云坊市（散修交易黑市）                  [经济中心]
└─ 禁地·血色试炼塔                          [章节副本]
```

后续章节：乱星海 → 灵界……（每章一张新大图）

### 5.2 区域设计规则

每个区域 = 一张 Tiled 地图 + `region.json`：

- 等级带（建议进入境界）
- 资源表（可采集物及刷新周期）
- 随机遭遇表（妖兽/事件/NPC）
- 昼夜与天气标记（影响遭遇率）

## 6. 主线剧情大纲（十章）

| 章 | 境界 | 主线梗概 |
|---|---|---|
| 一 | 凡人 | 七玄门杂役张铁（主角）偶得神秘小瓶（催熟灵药的逆天金手指），被墨大夫收为弟子 |
| 二 | 炼气 | 发现墨大夫欲夺舍自己的真相，反杀脱身；七玄门卷入江湖仇杀，离乡 |
| 三 | 炼气 | 入黄枫谷为记名弟子，百药园杂役，暗中用小瓶培育灵药积累资本 |
| 四 | 筑基 | 血色试炼塔夺宝混战，结识挚友厉师兄（后期重要伏笔）；抢得筑基丹 |
| 五 | 筑基 | 门派大比崭露头角；魔道入侵战争爆发，被迫卷入 |
| 六 | 结丹 | 战乱中寻得上古洞府传承，结丹成功；发现小瓶来历的第一条线索 |
| 七 | 元婴 | 挚友陨落真相揭露，复仇线开启 |
| 八 | 元婴 | 远赴乱星海寻找小瓶源头 |
| 九 | 化神 | 小瓶真相反转（它选择了你，还是你利用了它？） |
| 十 | 化神 | 渡劫飞升前夜，了断恩怨（开放式结局→资料片接口） |

> 叙事原则：主线强制推进节奏慢，支线和自由探索随时可做；关键抉择记录进 `world_state`，影响部分 NPC 存亡与结局细节。

## 7. 任务系统（content/quests/）

```jsonc
// quest 示例结构
{
  "id": "qs_caixia_wolf",
  "name": "彩霞山的狼患",
  "type": "side",             // main | side | daily | hidden
  "giver": "npc_id",
  "prerequisites": { "realm": "炼气3层", "quests": [] },
  "steps": [
    { "kind": "kill", "target": "mob_gray_wolf", "count": 5 },
    { "kind": "talk", "npc": "npc_id" }
  ],
  "rewards": { "lingshi": 50, "items": ["huiqi_san"], "exp_qi": 100 }
}
```

- 主线约 60 个、支线首期 40 个、每日任务模板 10 个
- 隐藏任务通过探索触发（无感叹号标记，符合"机缘"主题）

## 8. 经济系统

- 货币：下品/中品/上品灵石（100:1 兑换）
- 产出：任务 > 采集 > 掉落 ≫ 挂机修炼
- 消耗：突破丹药 > 功法兑换 > 装备强化
- 坊市 NPC 商店每日随机刷新（声望折扣）；黑市卖违禁品但可能遇劫

## 9. 手机端体验设计

| 场景 | 方案 |
|---|---|
| 移动 | 左侧虚拟摇杆 + 点击地面寻路（二选一可切换） |
| 交互 | NPC/采集点靠近自动弹出气泡按钮，单手可达 |
| UI | 底部抽屉式面板，safe-area 适配刘海屏 |
| 存档 | IndexedDB 自动存（每 5s + 关键节点），换设备靠导出存档码 |
| 性能 | 首屏 ≤ 3MB；纹理合图；场景分块加载 |

## 10. 内容管线规范（AI 协作核心）

1. **Schema 即法律**：新增任何内容必须先在 `src/systems/schemas.ts` 定义 zod schema
2. **一物一文件**：`content/items/<id>.json`，id 全局唯一 kebab-case→snake_case
3. **CI 校验**：`npm run validate` 在部署前跑，引用断裂即失败
4. **文案规范**：描述文本 ≤200 字，文风参考古典白话+修仙术语表（见附录 A）
5. **数值基准**：以"炼气一层裸装凡剑=攻 10"为锚点，各境界倍率表见数值平衡文档（待建）
