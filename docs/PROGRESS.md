## V2.1 恩仇系统（2026-08-30 · DEVELOPMENT_PROCESS §6.1 · v2-grudges）

**关系图 → 恩仇闭环**：偷/送礼双向写回（好感± → 恩仇类型自动推导），阈值成就 → 事件风暴「报恩/寻仇」。

- schema：`relations.{npcId} = { affinity, grudge, type?: mentor|rival|debt|spouse|enemy, lastGiftDay? }`
- 写回：**偷摘被目击** 记恨+1 好感-2（张二等 watchRadius 依辰时表在场）；**送礼** G 键（NPC `likes` 收礼清单，背包持有即可赠出）首礼好感+8、七日内重复只+1（防刷）
- 类型阈值：记恨 ≥4 结怨(rival)、≥8 成仇(enemy)；好感 ≥30 欠情(debt)、≥60 为师(mentor)；**仇重于恩**——记恨优先盖过旧恩
- 事件风暴通用化：trigger 三族条件（旷工/记恨/好感）可组合叠加，consequences 可赠灵石(报恩)、清记恨(寻仇)、还人情——新增 `张二报恩`（好感≥40 → 赠灵石12 + 情债-30）、`张二寻仇`（记恨>6 → 扣灵石15、风评-5、记恨清偿）
- 恩仇事件皆 once 防刷，入档 `world.events`，重载不重触发
- 送礼清单首批人物：张二/李三（七叶灵草）、墨大夫（百年灵芝）

**门禁**：validate ✓ build ✓ sandbox-sim 91/91（含恩仇类型推导优先级/衰减/三族条件/后果清算 16 项） combat ✓ quest 52/52 qa-local 38/38（8.96 送礼→报恩、8.97 寻仇）

**试玩具体观察（playtest-observation，真实 preview 游玩）**：
> "善缘"与"药园经济"是两条互相排挤的路——送礼花灵草（机会成本：市价 3 灵石/株），卖草换灵石，二选一；
> 且送礼按旬衰减（首礼+8、旬内再送+1），真亲善须隔旬经营而非一把梭。
> 好感攒满 40，张二竟在墙根塞来灵石十二枚（灵石 20→32，情债-30 了结）——小农户品换来的个体亲善，回头全部兑现。
> 自此「恩仇因果链」闭环成立：**偷摘→记恨→结怨→寻仇** 与 **送礼→好感→报恩** 两条可被玩家读出并主动利用的路线。
