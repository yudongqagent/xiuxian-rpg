## 标杆共识（2026 在线资料）

1. **社交是核心循环，不是侧系统**（Stardew / Fields of Mistria）——"life sim 四支柱：模拟日常、关系为核心、自定义表达、世界营造"（switchbladegaming 2026）。社交关系本身构成推进/解锁/分歧，而非附属物品。
2. **关系要双向、可积累、有后果**——偷/抢/救/送礼 → 好感/记恨 ±；阈值 → NPC 报恩/寻仇等活体响应（Darkest 世代家族、衔火话的"我记得你"）。NPC 记得玩家，世界随关系改变面貌。
3. **礼物系统是黄金标准武器**——Stardew：每人 liking 物表、隔日冷却、送错扣好感、节日引爆高潮。送礼不是交易而是情绪投资。
4. **时间/季节/日程本身是深度的来源**——NPC 日程、节日、随时辰变化的出没，形成可被打探、被利用的"钟表逻辑"（Sims3 突发、ACNH 岛屿日常）。
5. **聚落/世代记忆**：世界记得玩家家族的作为（世代农场游戏、暗黑庄园）。玩家会"读"关系、计划世代。
6. **开放世界的"软护栏"**：危险区不硬锁、靠信息差+伤害+温和惩罚（重伤回安全区）引导，而非传送门锁死章节。

## 2026-08-31 深度对标分析

基于 2026 年在线资料（Stardew Valley / Spiritfarer / Moonlighter / Maplestory Reboot / 混合休闲 2026 报告）补充分析：

| 标杆金线 | 标杆做法 | 本作差距 | 消化路径 |
|---|---|---|---|
| **活动多样性**（Stardew "整个水果篮"） | 采药/钓鱼/烹饪/挖矿/战斗多线并行，活动间互锁（采→炼→卖→升级→探更深） | 当前只有采药+战斗两笔，炼丹入不敷出（124<136），缺少让玩家"上瘾"的活动链 | V3 节日/支线解锁新活动类型（钓鱼、符箓、炼器），V2.4 先打通救人/抢夺两条新互动线 |
| **关系路径多样性**（Spiritfarer 多层任务链驱动剧情） | 送礼/救人/抢夺/婚姻/师徒多种关系路径，每条有独立的情感回报 | 仅送礼+偷摘两条路径，缺少"救人"（好感飙升）和"抢夺"（记恨爆发）的高情感密度动作 | V2.4 写回：`救`→好感+情债，`抢`→记恨+风评，spouse/mentor 变体（新关系类型） |
| **世代记忆**（Stardew Generations / Darkest Dungeon） | 世界记住家族所为，下一世继承关系/声望/遗产 | 寿元尽头"定格之世"，无转世延续 | V2.5 转世遗赠：新周目继承部分关系图+风评+特殊道具 |
| **事件驱动留存**（混合休闲 2026：event-led loops） | 定期触发世界事件（节日/灾害/入侵），形成"期待感" | 事件仅"杂役院失窃"一例，缺少周期性世界事件 | V3 节日系统：灵石拍卖会/血色试炼开启/魔道入侵——定期改变地图内容和NPC行为 |
| **经济深度**（Moonlighter 双循环） | 探索→获取→交易→升级→探索更强区域，形成闭环 | 炼丹经济失衡，坊市仅买卖两笔 | V3 数值锚点回归 + 丰富商店品类/配方（GDD §2/§3） |
| **RPG 留存基准** | D1 40-60% / D7 25-40% / D30 15-25%（2025 Playio 报告） | 单次体验完整但缺少"每日回归动力" | V3 节日/日常事件提供回归理由，V2.4 关系深度提供情感投资回报 |

**结论**：V2.1-V2.3 已消化社交核心循环、时间深度、软护栏三大金线。下一阶段的核心差距在 **活动多样性**（"整个水果篮"）和 **关系路径多样性**（救人/抢夺/婚姻/师徒），V2.4 写回恩仇扩路径是最高效的下一步——用最小代码量解锁最大情感密度。
