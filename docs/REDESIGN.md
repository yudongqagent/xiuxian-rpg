# 《凡人仙途：因果沙盒》重构设计（2.0 版）

> 版本 v2.0 · 2026-08-29 · 在现有一期（主线 RPG）之上重做的 2.0 开放世界设计
> 定位：纯单机沙盒，保留已验证的 Phaser+Vue+内容管线+门禁，复用全部内容资产，重构为"世界模拟"驱动
> 本文档是 2.0 所有内容生成的唯一权威依据；冲突时以本文档为准

---

## 1. 为什么要 2.0：一期的问题诊断

一期《凡人仙途》是**好而短的动作切片**——主线穿珠子，玩家被牵着走。"最好玩的修仙开放世界"的爽感来源不是更长的珠链，而是**涌现**：玩家做出的选择，产生他们没预料到、但系统诚实回应的后果。

### 1.1 一期留存的资产（不丢弃）

| 资产 | 价值 |
|---|---|
| 内容管线（JSON+schema+validate） | 仍然是最快的 AI 量产通道 |
| 回合制战斗（意图提示/连携/怒气） | 数值与手感已验证，直接继承 |
| 打坐/突破/修为体系 | 凡人流的成长底子，需补展现与心魔 |
| 掌天瓶药圃 | 已有挂机+微操作的雏形，是"工序即乐趣"的起点 |
| 存档容错（IndexedDB/存档码） | 数据保守原则直接继承 |
| 门禁 G1–G6 | 全流程守住质量线 |
| 七图十六任务 | 作为 2.0 的启动内容，重制而非删除 |

### 1.2 一期必须拆掉的三个墙

| 一期问题 | 症状 | 2.0 对策 |
|---|---|---|
| **章节锁墙** | portal 按主线逐章开放，玩家被地图和剧情双线牵引 | 危险度带替代章节锁：世界全部可达，靠"打不过+寿元压力"软门槛 |
| **NPC 是布景** | 所有 NPC 只有固定三句对话，不记得玩家的行为 | NPC 有日程/欲望/关系图，行为可记账、可恨、可报恩 |
| **地图是布景** | 世界只在玩家经过时"活着"，药草刷新靠硬编码 | 区域生态+刷新表+事件风暴，世界有自身的生命周期 |

## 2. 设计论点（Thesis）

**最"好玩"的修仙开放世界 = 因果沙盒。**

把修仙题材独有的"缘"（际遇、恩怨、机缘）实现为**系统**而非**剧情**：世界有它自己的时间、欲望与生死；玩家的每一个选择都改变世界状态，而世界以日程、事件、关系——而不是任务弹窗——诚实地回馈。

三个原力钩子（hooks）决定"好玩"的来源：

1. **寿元倒计时**（凡人流的底层焦虑）：凡人 80 年、炼气 120、筑基 200……每一步大突破既是"续命"也是"豪赌"。寿元是比灵石更硬的货币——它逼玩家做选择，制造张力。
2. **世界不是布景**（系统诚实回应）：NPC 记得你抢过他的药草；被你救过的修士会在危险时帮你挡一刀；区域有兽潮、坊市有黑市、门派有兴衰。因果关系链让"探索"永远有新故事。
3. **机缘是系统不是任务**（程序化+可遇不可求）：秘境、遗蜕、封印异宝由引擎生成并周期刷新，但需要**信息**（打听、占卜、神识）来定位。没有感叹号，只有线索。

## 3. 设计支柱 2.0（对一期四支柱的升级）

| 支柱 | 一期 | 2.0 升级 |
|---|---|---|
| **凡人感** | 资源稀缺、突破可失败不删档 | 增加**寿元压力**；负反馈保持温和（不删档不降境界） |
| **探索驱动** | 每图藏 1 个秘密 | 每区域有**生态周期**+**程序化机缘**；信息即资产，探索靠线索而非地图标点 |
| **配置化内容** | 一切进 content/，CI 校验 | 保留；新增 schema 支持**事件/日程/刷新表**等沙盒数据 |
| **碎片可玩** | 3 分钟一个完整动作 | 保留；挂机（打坐/药圃/慕名委托）收益封顶，离线是甜点 |

### 3.1 新增支柱：信息即资产

- 地图有迷雾（已探索区域才亮）；区域信息要花灵石或人情换
- 机缘点刻意不做成"宝箱图标"，而是传闻碎片：坊市有人抱怨"东岭夜里泛金光"，自己去夜探
- 神识数值化：神识高的玩家路过秘境有微弱的"气机感应"提示（台阶拉开差距）

## 4. 核心循环 2.0

```
         ┌────────────────────────────────────────────┐
         │            世界模拟（永远在跑）               │
         │  时辰/季节 → NPC 日程 → 关系图 → 事件风暴     │
         └────────────────────────────────────────────┘
                     ▲      │ 事件/线索/危险
                     │      ▼
    ┌──────┐   想活/想变强   ┌──────┐  用资源实现欲望  ┌────────┐
    │ 欲望  │────────────────▶│ 行动  │───────────────▶│ 体力+时间│
    │(寿元/ │ 采集·炼丹·战斗   │(探索/ │  修炼·突破·交贡  │  (流逝) │
    │ 命格/ │ 交易·结缘·冒险   │ 修炼 )│  情报·募徒·置产   │        │
    └──────┘                 └──────┘                └────────┘
        ▲                                               │
        │            世界状态改变（因果回写）               │
        └───────────────────────────────────────────────┘
```

- **欲望**：寿元倒计时、当前命格任务（天机老人批命）、自己定的目标（"三年内筑基"）
- **行动**：一期全部系统保留（战斗/炼丹/装备/坊市/药圃），新增采集微操作与借势战斗
- **体力+时间**：移动/战斗/炼丹消耗"时辰"；时间是世界模拟的燃料

## 5. 开放世界结构：危险度替代章节锁

### 5.1 区域 = 危险度带 + 生态 + 刷新表

```jsonc
// content/regions/<id>.json（新增 schema）
{
  "id": "taiyue_shanmai",
  "name": "太岳山脉",
  "danger": "筑基初",           // 建议进入境界；软门槛，不锁门
  "qiDensity": 2.5,             // 复用现有
  "ecosystem": {                // 生态：妖兽习性→活动时段/领地
    "predators": [ { "enemy": "huishou", "tier": 80, "time": ["晨","夜"] } ],
    "prey":    [ { "enemy": "lingzhu",  "cowardly": true } ]
  },
  "gather": { "lingcai": ["qiannian_lingru"], "regen": "3日" },
  "events":  { "resourcePool": ["兽潮","灵脉躁动","秘境显形"] }
}
```

- 世界**全部可达**，不做 portal 锁门；打不过 = 你还没准备好（凡人流本色）
- 秘境是区域上**周期刷新**的洞窟/传送门，出现时全坊市有传闻线索

### 5.2 主线 ≠ 墙，主线 = 剧本事件

- 主线从"前置链"改为**世界剧本事件链**：满足境界/声望条件即可触发，触发后进入一段沙盒窗口（如"血色试炼塔开启 7 日"），过期再等下一轮
- 玩家可以无视主线一辈子——世界照常运转，只是没了舞台事件

## 6. 世界模拟层（2.0 核心新增系统）

### 6.1 时间轴

- 游戏内时钟：**时辰（1/8 日）→ 日 → 月 → 季节**（一个时辰约现实 1 分钟）
- 移动/战斗/炼丹消耗时辰；打坐、药圃、慕名委托消耗"挂机时长"（可离线，收益封顶）
- 存档按"游戏日"做世界快照，恢复保真

### 6.2 NPC 日程与欲望（NpcSchema 升级）

```jsonc
{
  "id": "momo_daifu",
  "schedule": {
    "卯时": "药园",
    "午时": "诊堂",
    "酉时": "居所"
  },
  "desires": { "get": "lingchong", "grudge": true, "affinity": { "player": 30 } },
  "relations": { "li_feiyu": "mentor", "wang_zhangmen": "owe" }
}
```

- NPC 每天按日程移动，玩家可在**其所在处**找到它（一期是静态站位）
- **关系图**：好感/记恨/恩情/婚约/仇家，玩家行为写入关系，NPC 的对话与帮助随关系改变
- **NPC 生死**：兽潮/黑市可能造成 NPC 伤亡，事件链上的关键 NPC 有"不死保护"（避免剧情断链）

### 6.3 事件风暴（涌现来源）

- 事件 = 数据模板 + 条件 + 后果，如：

| 事件模板 | 触发条件 | 后果 |
|---|---|---|
| 兽潮 | 区域妖兽密度 > 阈值，每 N 日 | 该区妖兽暴增、商路中断、坊市涨价 |
| 坊市黑市 | 随机概率+有声望门槛 | 违禁品交易，可能遇劫 |
| 门派大比 | 每季固定 | 比斗舞台，奖励+声望 |
| 秘境显形 | 区域事件池轮转 | 洞窟出现，传闻散布，限时探索 |
| 天机批命 | 每年立春 | 玩家获得"命格任务"（一年期限） |
| 恩仇现身 | 关系图有未解仇/恩 | 仇家劫杀 / 恩人来报 |

- **涌现测试**：每个事件必须回答"它会改变玩家的什么选择？"——否则不进内容池

## 7. 修炼与寿元 2.0

### 7.1 寿元 = 硬的黄油（核心张力）

- 境界 → 寿元上限（复用 GDD 数值：凡人 80 → 炼气 120 → 筑基 200 …）
- HUD 常驻**寿元倒计时**显示；大境界突破 = "续命窗口"
- 突破失败的挫败保持温和（耗丹重伤不降境界，已有）；寿元用尽 = 重伤抱恙（**不删档**）：修为暂锁、需要续命机缘（筑基丹/延寿功法）救回
- 一期"不会死"的容错红线保留：**死亡 = 重伤回城扣灵石**，但寿元推进不可回退（唯一硬惩罚）

### 7.2 修炼序列补齐

- 一期已有：打坐回灵产修为、突破仪式、掌天瓶药圃
- 新增：
  - **顿悟**：低概率事件（悟性影响），修为暴涨+短暂无支线压力（"悟"的爽感）
  - **心魔**：大突破失败衍生的情志事件（可遇丹药压），失败不掉级但有负反馈剧情
  - **突破仪式展现**（补一期缺口）：全屏动画/天象/门派传闻，让"续命"有仪式感

### 7.3 战斗 2.0（继承+三新）

继承回合+意图提示+连携+怒气。新增：
- **借势**：可布陷阱/借地形（悬崖推落=一击必杀但妖兽素材损毁）——"打不过就智取"的凡人流解法
- **袭杀/偷袭**：潜行靠近妖兽背身=先手，成功率受神识与身法
- **活捉**:  妖兽濒死可选择活捉→**灵兽契约**（二期），作为材料/骑乘/战斗伙伴

## 8. 经济与制造 2.0

- 货币分品：下/中/上品灵石 100:1（对齐 GDD §8，一期未做）
- 坊市 NPC 商店**每日随机刷新** + 声望折扣（一期固定货架）
- 黑市：违禁品/高折价，可能遇劫（事件风暴接入）
- 炼丹**火候小游戏**：对齐 GDD §4.3（一期纯概率）；失败产废丹可售（负反馈温和）
- 装备词条：固定+0~3 随机词条（GDD §4.2），鉴定玩法（二期炼器）

## 9. 新手引导 2.0（软引导，非教程墙）

一期无引导（被列为缺口）。2.0 用**杂役生活打样**：

1. 序章"杂役七日"：天气固定的教学窗口，只教四件事——采集/炼丹/交易/逃命（全程十分钟）
2. 面板渐进解锁：第十章入学才开货币、炼丹、神识等高级面板
3. 可关闭的提点 toast（first-time 标志，入存档）
4. 引导不锁探索：玩家随时走出村，代价是危险与时间

## 10. 存档 2.0（世界快照）

- 一期存玩家+任务；2.0 增存**世界状态**：

```ts
interface WorldSnapshot {
  time: { day: number; hour: number; season: number }
  npcStates: Record<npcId, { pos, affinity, desires, alive }>
  eventQueue: Array<{ endAt: number; data }>   // 未到期事件
  regionStates: Record<regionId, { density, nextEvent }>
  seenHints: string[]                          // 新手提点去重
  fog: Record<mapId, bitmask?>                 // 探索迷雾
}
```

- 快照大小受控（IndexedDB 足够）；保真恢复不破坏事件
- 导出/导入存档码沿用（体积随快照增大，拆分"世界码"与"玩家码"二期）

## 13. 验收主张（DoD 前置）

2.0 的"完成标准"不只是 G1–G6 门禁绿，而是每一条功能要回答：
1. **涌现性**：这个系统能产生多少种"我没设计过但合理"的结果？
2. **诚实性**：世界回应玩家的选择了吗？（恩怨是否记账、事件是否回写）
3. **凡人感**：玩家是否感到"资源与时间都在燃烧"？
4. **碎片可玩**：3 分钟能否完成一个完整的因果动作（采集→变故/交易→回报）？

检验方式 = **涌现测试脚本**（scripts/sandbox-sim.ts）：模拟 N 个游戏日无死锁、无资源爆炸、无坏档、无剧情断链。
